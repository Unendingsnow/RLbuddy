# RL Buddy audit and feature roadmap

Reviewed October 31, 2026 for the v0.5.1 illustrated garage beta. This is a source review and automated-test report, not Epic approval, a penetration test, or a guarantee of game compatibility.

## Changes made during this audit

- Generated and integrated an original haunted hot-rod workshop and a new Jackshaft portrait. The original animated character remains. Assets are local, and the new background is dashboard-only. The transparent overlay does not load it. See [art provenance and exact prompts](ART-DIRECTION.md).
- Emergency pause now latches in memory and stops capture, pending reactions, coaching and benchmarks before disk persistence. Failed writes cannot prevent the stop; an old resume operation cannot clear a newer pause. Resuming keeps capture off.
- Capture-off controls stop the old stream immediately and retain an in-memory off state if the settings write fails. Successful explicit re-enabling releases only the corresponding current latch. Chat/event AI remains available when only capture is stopped.
- Clarified that saving frames locally and sending live vision frames are independent choices. Structured name anonymization does not redact screenshots.

## Findings still open

### P1: Live generated banter has an incomplete advice boundary

`src/personality/quality.js` rejects selected phrases, but it is not a semantic policy boundary. For example, `Take the left boost and challenge early.` passes the current observation validator. Imported local personality templates in `src/personality/engine.js` bypass that validator; `src/personality/registry.js` validates their format, not the meaning of every line. Prompts asking for entertainment do not guarantee the model will avoid tactical advice.

Before broadly marketing competitive-play compatibility, provide a conservative profile using reviewed event reactions during matches, with generative coaching confined to completed matches or explicitly identified recorded replays. Audit the built-in lines too. Imported packs need provenance, content review and a preview step before joining that profile. Expanding a regex alone does not close this finding. Unrestricted live AI remains optional and is not described as ban-proof.

### P2: Deletion acknowledges the request before disk completion

`MatchMemory.delete` removes a match from the index immediately while `DiskStore` performs deletion asynchronously. The IPC response can succeed even if unlink fails. A warning is reported, but files can remain and the match can reappear after restart.

Return a per-operation result after files are actually removed. Keep failed/pending deletion visible and retryable; do not treat a queued request as confirmed erasure. Exercise permission-denied failures and restart recovery. This is an outstanding privacy/reliability issue, not fixed in this art release.

### P2: Background animation needs a real performance budget

Both windows disable Electron background throttling, and the Jackshaft renderer has a recurring sprite timer. The dashboard may keep doing work while hidden. No actual game-FPS regression was measured in this audit.

Suspend hidden dashboard animation independently from the visible overlay. Measure game frame times, CPU/GPU use, memory growth and warm/cold inference latency on several GPU vendors, with vision off and on. Use those measurements to set presets. Static generated artwork does not require ongoing model inference.

### Release work remains

The beta is unsigned. Signing, a public prerelease download, upgrade/rollback validation, longer hardware/gameplay testing and marketplace licensing/moderation are still release work. A clean production npm audit covers npm dependencies, not the bundled Chromium/Electron runtime or build-tool advisories. See [release checklist](RELEASING.md).

## Rocket League compatibility evidence

The inspected integration reads the documented local Stats API (`src/game/stats-client.js`) and uses OS window/display capture (`src/vision/live-capture.js`). No injection, game-memory reader, automated gameplay input or automatic game-chat posting was found in those paths. The existing coaching gate rejects live/unknown game states, cancels on match start and hides prior reviews.

Epic's [third-party mod policy](https://www.epicgames.com/help/c-37599050/c-42869540/can-i-use-third-party-mods-with-rocket-league-a22460826?lang=en-US) prohibits online competitive advantage, unreleased-content access and interference with the service. It does not certify this app. The [official EAC announcement](https://www.rocketleague.com/news/easy-anti-cheat-comes-to-rocket-league-on-pc-today) introduced the Stats API for broadcast tooling, but that does not approve every use of the data. [Tournament rules](https://www.rocketleague.com/competitive/rules) require separate event-specific review.

The recommendations below are design judgments intended to reduce competitive-advantage risk, not a promise that a third party will allow them.

## Recommended features, in order

| Feature | Why it is useful/fun | Boundary to preserve |
| --- | --- | --- |
| Competitive profile | Reviewed, event-specific roasts without uncertain live tactics; clear personality provenance | Curated live content, no open-ended AI tactics or unreviewed imports |
| Replay Lab / receipts | Timestamped teammate combinations, saved evidence and explicitly uncertain observations; click from a claim to the evidence | Completed matches and explicit recorded-replay lifecycle only; never treat a goal replay as offline play |
| Post-match roast cards | Export a funny illustrated result/quote card using the new garage art | User-initiated local export after the match; hide names by default; no automatic posting |
| Practice notebook | Save one drill from a review, log attempts and follow progress over time | Manually logged practice goals; no real-time match instructions or control automation |
| Cosmetic garage progression | Collect props, costumes and celebration animations from recorded milestones | Cosmetic effects in this app only; no changes to game assets or inputs |
| Personality audition | Preview imported voices against goals, saves and losses; inspect profanity and reading time | Untrusted packs remain data-only; audition is not proof that all lines meet a competitive policy |

The [official Stats API](https://www.rocketleague.com/developer/stats-api?lang=en) distinguishes `ReplayCreated` (Match History replay) from goal-replay events and documents replay seeking. A Replay Lab should establish that lifecycle explicitly; the general `bReplay` flag covers both kinds. Current RL Buddy does not implement that dedicated replay mode. Keep current live-game restrictions until it does.

Avoid opponent boost tracking, tactical radar, real-time positioning instructions, automated inputs and automated chat. Missing evidence should remain unknown instead of becoming a confident coaching claim.

## Validation scope

The local Node suite, Electron desktop smoke flow and supported compact-window layout check pass. Tests cover failed-write pause behavior and stale resume races; additional capture-stop regressions accompany the latch change. Packaged checks verify startup and the preload bridge. The production npm dependency audit reports zero advisories at review time. Paid-provider calls, long real matches, anti-cheat certification and multi-GPU FPS comparisons were not performed for this release.
